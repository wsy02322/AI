# 验收

用 **真实** `GEMINI_API_KEY` 测。

## MVP

| # | 步骤 | 通过 |
|---|------|------|
| 1 | 配 key，HTTPS 打开 UI | 前端无长期 API key；通话 WSS 打到 **本站** 而非浏览器直连 googleapis |
| 2 | 只说麦克风，中文短句 | 语音回复；非数秒级串联 |
| 3 | 模型说话时插话 | barge-in |
| 4 | 共享大字页面，问内容 | 回答与画面一致 |
| 5 | 共享后静音 ≥10s 再问 | 仍 1 fps（非 ~0.3） |
| 6 | 浏览器停止共享 | 采集停 |
| 7 | README：10 分钟内跑通 | 有 `.env.example` |
| 8 | VPS：独立端口 + 反代可访问（用户给域名后） | 不与其它服务抢端口 |

## 失败

- 无语音 / 无屏享 / 640×480 屏享  
- LiveKit / vision-demo / 原生 App 当 MVP  
- 默认 C2S，中国用户无法通话  
- 宣称超越官网但仅套同一 API
