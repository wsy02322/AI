# 验收

在 **真实 Gemini Live API** 上测，不要只测页面能打开。

## MVP 通过

| # | 步骤 | 通过 |
|---|------|------|
| 1 | 配置 `GEMINI_API_KEY`，启动官方改编后的 server，浏览器打开 UI | 无 key 泄漏到前端网络面板 |
| 2 | 只开麦克风，说一句中文短句 | 模型用语音回答，延迟主观接近网页 Gemini Live（允许略慢，禁止数秒级串联感） |
| 3 | 模型说话时插话 | 播报停止或明显让路（barge-in） |
| 4 | 共享一个 **大字** 页面（标题级），问「屏幕上写了什么」 | 回答与画面一致 |
| 5 | 共享后保持静音 ≥ 10s，再问画面 | 仍按 **1 fps** 在送帧（可用代理/日志数 JPEG；禁止静音掉到 ~0.3 fps） |
| 6 | 浏览器「停止共享」 | 采集停，UI 回到未共享 |
| 7 | README 能让生人 10 分钟内跑起来 | 有 `.env.example` 与命令 |

## 失败则不算过

- 只能打字、没有语音出  
- 只能摄像头、没有 `getDisplayMedia`  
- 屏享被缩成 640×480 且未说明  
- 把 LiveKit/vision-demo 当 MVP 骨架  
- 改了 micropigeon OWUI 来「顺便」接 Live  
- 宣称「已超越 Gemini 官网」但只是套了同一 API
