# 新项目 Agent 守则

## 原则

1. 对标网页 Gemini Live（能说、能看屏、可打断）。  
2. 简单：一个 Web 服务 + Google Live；5 人桌面即可。  
3. **可用性优先于理论最低延迟**：用户多在中国 → 默认 VPS 中继。

用户已确认：新 GitHub 仓库、同 VPS 部署、桌面 Web。

## 开工向用户要

- `GEMINI_API_KEY`  
- 对外 **HTTPS 子域名**  
- VPS 可用端口（默认建议 8090）

## 口径

- 中国用户：页面开你的域名；通话不直连 Google。  
- 延迟：比直连 Google 略多一截国际 RTT，仍须像通话而不是「先转写再播报」。  
- 不要做 App 来「优化延迟」。
